## 一、归档概述

本文档记录 YOLO11n v3 256×256 模型作为本项目最终车牌检测模型的归档信息。该模型是 YOLO11n v3 系列中精度与速度的平衡选择，已替代之前的 192×192 版本部署到 ESP32-P4 设备。

### 选择理由

1. **精度提升**：相比 192×192，256×256 在远距离检测上有更好表现
2. **速度可接受**：推理时间约 400ms（估算），仍维持准实时能力
3. **mAP50 不变**：0.9950（与 320×320 相同），检测召回率无损失
4. **flash 占用合理**：2.98 MB，仅比 192×192 多 120 KB

## 四、固件配置

### 4.1 sdkconfig 配置（已修改）

```
# models: lp_gallery
CONFIG_FLASH_LP_GALLERY_YOLO11N_256_V3=y          # 启用 256 模型嵌入 flash
# CONFIG_FLASH_LP_GALLERY_YOLO11N_192_V3 is not set  # 禁用原 192 模型
CONFIG_LP_GALLERY_YOLO11N_256_V3=y                # 默认模型选择 256
CONFIG_DEFAULT_LP_GALLERY_MODEL=3                 # 枚举值 3 = YOLO11N_256_V3
CONFIG_LP_GALLERY_MODEL_IN_FLASH_RODATA=y         # 模型嵌入 flash rodata
CONFIG_LP_GALLERY_MODEL_LOCATION=0                # location=0 (flash_rodata)
```

## 七、备选模型切换方式

如需切换到其他分辨率或特殊版本，修改 sdkconfig 后重新构建烧录即可：

| 目标模型 | sdkconfig 修改 |
|---------|---------------|
| 320×320（高精度） | `CONFIG_FLASH_LP_GALLERY_YOLO11N_320_V3=y` + `CONFIG_DEFAULT_LP_GALLERY_MODEL=0` |
| 224×224 | `CONFIG_FLASH_LP_GALLERY_YOLO11N_224_V3=y` + `CONFIG_DEFAULT_LP_GALLERY_MODEL=4` |
| 192×192（原部署） | `CONFIG_FLASH_LP_GALLERY_YOLO11N_192_V3=y` + `CONFIG_DEFAULT_LP_GALLERY_MODEL=5` |
| blur_lp_v2（模糊场景） | `CONFIG_FLASH_LP_GALLERY_YOLO11N_BLUR_LP_V2=y` + `CONFIG_DEFAULT_LP_GALLERY_MODEL=6` |

切换步骤：
1. 修改 `sdkconfig` 中对应的 `FLASH_LP_GALLERY_*` 和 `DEFAULT_LP_GALLERY_MODEL`
2. 执行 `idf.py build`
3. 执行 `idf.py -p COM15 flash`
