# 第二部分：LPRNet 模型进化历史

## 阶段一：原始 LPRNet（纯 CNN，96×24 输入）

### 修改节点 L1.1：原始 CNN 架构

| 项目 | 内容 |
|------|------|
| **修改时间** | 项目早期（具体时间未记录） |
| **修改内容** | 纯 CNN 架构，无预训练骨干网络，输入 24×96，70 类字符集（31 省 + 使领学警港澳 + 26 字母 + 10 数字） |
| **架构** | Conv(3→64) → Pool → Conv(64→128)×2 → Pool → Conv(128→256)×2 → Pool(2,1) → Conv(256→512) → Conv(512→512) → Conv(512→num_classes) |
| **训练参数** | Adam + StepLR, batch_size=32, 30 epochs, **无数据增强** |
| **修改原因** | 项目初始阶段，建立车牌识别基线 |
| **效果评估** | 仅支持蓝牌，无数据增强，性能有限 |
| **数据来源** | `LPRNet模型演进分析.md` |

## 阶段二：MobileNetV2 迁移学习

### 修改节点 L2.1：引入迁移学习 + BiLSTM

| 项目 | 内容 |
|------|------|
| **修改时间** | 阶段一之后 |

| **数据来源** | `LPRNet模型演进分析.md` |

## 阶段三：改进 LPRNet v2（纯 CNN + Dropout，128×32）

### 修改节点 L3.1：改进 CNN + 大幅增强 + 绿牌支持

| 项目 | 内容 |
|------|------|
| **修改时间** | 阶段二之后 |
| **修改内容** | 回归纯 CNN（无预训练骨干），引入 Dropout2d(0.3) 正则化，**首次支持蓝牌+绿牌**，字符集调整为 67 类（去掉 I 和 O） |
| **架构** | Conv(3→64) → MaxPool → SmallBasicBlock(64→128) → MaxPool → SmallBasicBlock(128→256) → MaxPool(2,1) → SmallBasicBlock(256→256) → Dropout2d(0.3) → Conv(256→256, 2×1) → BN → ReLU → Dropout2d(0.3) → Conv(256→num_classes, 1×1) |
| **输入尺寸** | **32×128**（后续所有版本标准） |
| **字符集** | **67 类**（31 省 + 25 字母去掉 I/O + 10 数字） |
| **训练参数** | **AdamW + OneCycleLR + AMP 混合精度** + 梯度裁剪(max_norm=5), batch_size=256, 100 epochs |
| **数据增强** | 10 种增强（亮度/对比度/饱和度/高斯噪声/高斯模糊/运动模糊/透视变换/阴影/雨滴/雾效），概率 0.8 |
| **修改原因** | 提升泛化能力，支持新能源绿牌，增强鲁棒性 |
| **效果评估** | 已训练 41 epoch，成为后续版本的基线 |
| **数据来源** | `LPRNet模型演进分析.md` |
