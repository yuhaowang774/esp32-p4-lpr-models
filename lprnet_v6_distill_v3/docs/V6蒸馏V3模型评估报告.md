# V6 蒸馏 V3 模型评估报告

## 1. 概述

**模型名称**：V6 蒸馏 V3（lprnet_v6_distilled_v3）

**目标**：解决 V6 蒸馏 V2 模型在 ESP32-P4 simcrop 测试中绿牌末尾字符丢失问题（267 个错误，占绿牌 8.6%）

**方法**：基于 V6 蒸馏 V2 成功方案，针对绿牌末尾字符丢失问题进行 3 项关键改进

**结论**：V3 模型在 PC simcrop 测试中绿牌完全匹配率达 100%，末尾字符丢失降为 0，成功解决目标问题

---

## 2. V2 → V3 改进要点

| 参数 | V2 | V3 | 改进理由 |
|------|-----|-----|---------|
| blank_logit_reduction | 0.3 | 0.1 | 减少 blank 产生，帮助末尾字符输出 |
| letterbox 宽高比范围 | (2.5, 6.5) | (2.5, 8.0) | 增加窄高比样本训练 |
| 绿牌样本加权 | 无 | 1.5x | 增强 8 位绿牌学习 |
| letterbox_prob (medium/full) | 0.5 | 0.6 | 更多 letterbox 场景训练 |
| 学习率 | 5e-4 | 3e-4 | 从 V2 权重微调级学习率 |
| STUDENT_WEIGHTS | V6 蒸馏 V1 | V6 蒸馏 V2 best | 在 V2 成功基础上微调 |

---

## 3. 训练过程

### 3.1 训练数据

- 训练集：121,395 张（蓝牌 58,239 + 绿牌 63,156）
- 绿牌加权：63,156 个绿牌样本 x1.5（生效）
- 验证集：15,174 张（蓝牌 7,280 + 绿牌 7,894）

### 3.2 训练结果

- **早停**：第 16 epoch 触发（PATIENCE=15）
- **原因**：从 V2 best 权重初始化，验证集 balanced_acc 在 epoch 1 就达 100%，后续无提升空间
- **Best 模型**：epoch 1 权重（balanced_acc=100.0%）
- **Final 模型**：epoch 16 权重（balanced_acc=99.9%）

### 3.3 模型选择策略

由于 best 模型（epoch 1）只是 V2 + 1 epoch 微调，V3 改进几乎未应用；final 模型（epoch 16）包含 medium 阶段 6 epochs 的 V3 训练（letterbox_prob=0.6、绿牌加权、blank_reduction=0.1），更适合本任务目标（改善 simcrop 表现而非验证集准确率）。

**决策**：使用 final 模型（epoch 16）进行后续 ONNX 导出、量化和部署。

## 4. 量化结果

### 4.1 ONNX 导出

- 模型：final_lprnet_v6_distilled_v3.pth → lprnet_v6_distilled_v3.onnx
- ONNX 大小：2457.6 KB
- onnxsim 简化：成功

### 4.2 INT8 量化

- 算法：KL 散度校准
- 校准样本：2048（50% clean + 50% letterbox）
- 输出：lprnet_v6_distilled_v3_int8.espdl（665 KB）

### 4.3 量化误差

| 层 | 噪声信号功率比 |
|----|---------------|
| /backbone.0/Conv | 0.147% |
| /backbone.15/Conv | 0.050% |
| /backbone.8/block/block.3/Conv | 0.010% |
| 其他层 | <0.010% |

**最大量化误差 0.147%**，量化质量优秀，对模型精度影响可忽略。

## 5. PC simcrop 测试结果

### 5.1 测试配置

- 测试集：6200 张 simcrop 图片（蓝牌 3100 + 绿牌 3100）
- 推理流程：复现 ESP32-P4 端侧（letterbox 128x32 + 归一化 + PyTorch float 推理 + CTC 解码 + V5 后处理救援）
- 模型：V3 final（epoch 16）PyTorch float

### 5.2 总体结果

| 指标 | V2 (ESP32 INT8) | V3 (PC float) | 改进 |
|------|----------------|---------------|------|
| 总体完全匹配率 | 95.48% | **99.95%** | +4.47% |
| 蓝牌完全匹配率 | ~96% | 99.90% | +3.9% |
| 绿牌完全匹配率 | 91.4% | **100.00%** | +8.6% |
| 绿牌末尾字符丢失 | 267 (8.6%) | **0 (0%)** | -267 |

### 5.3 绿牌末尾字符丢失分析

- **V2**：267 个绿牌末尾字符丢失（占绿牌 8.6%）
- **V3**：0 个绿牌末尾字符丢失（0%）

V3 的 3 项改进（blank_logit_reduction 0.1、letterbox 宽高比 8.0、绿牌加权 1.5x）成功解决了绿牌末尾字符丢失问题。

### 5.4 V3 错误样本

V3 仅有 3 个蓝牌错误（0.10%），无绿牌错误。错误详情见：
`./outputs/simcrop_test_v3_results.json`
